# Reference Desk Queries

A browser-based SQL practice page for LIS 4050 (Library and Information Technologies) at the University of Denver. Students write SQL against four small library tables and see the results, with no install or server needed.

Open the page: [Reference Desk Queries on GitHub Pages](https://lagypin.github.io/lis4050-sql-practice/)

The page runs queries with [sql.js](https://github.com/sql-js/sql.js), used under the MIT license.
